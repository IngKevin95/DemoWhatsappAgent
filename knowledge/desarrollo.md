# Área de Desarrollo

## Desarrollo de Software - Construcción y Mejoras del ERP

El área de desarrollo es responsable de construir, mantener, testear y evolucionar el ERP DemoCorp y sus complementos.

### Servicios ofrecidos
- Desarrollo de nuevos módulos y funcionalidades personalizadas.
- Corrección de bugs y errores reportados por soporte técnico.
- Construcción de integraciones, APIs personalizadas y automatizaciones de procesos.

### Proceso de Ingeniería
1. Recepción y análisis del requerimiento desde el CRM.
2. Diseño técnico de base de datos e interfaces.
3. Codificación de la solución.
4. Pruebas de calidad (QA).
5. Despliegue seguro en producción.

### Consultas de clientes
- Estado de requerimientos, alcance funcional aprobado, fecha estimada de entrega y cambios incluidos. Requiere el número de solicitud del CRM.

### Preguntas frecuentes
- **¿Cuándo estará disponible mi mejora?** El consultor comercial o técnico puede validar la fecha de despliegue usando el ID del requerimiento del CRM.
- **¿Qué incluye el desarrollo contratado?** Se rige bajo el documento de alcance técnico aprobado en la cotización.

### Recomendaciones
Todo desarrollo nuevo debe validarse exhaustivamente en la base de pruebas antes de pasarse a producción.
