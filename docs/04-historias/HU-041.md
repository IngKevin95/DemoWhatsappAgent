# HU-041: Aceptar (Sí) desbloquea el flujo

## Descripción

Cuando el usuario toca el botón "Sí, acepto", se registra el consentimiento y el bot continúa con la
atención normal (LLM + tools).

## AC-1: Aceptación registra y continúa

**Given** un contacto con `consentimiento` NULL que recibió el gate
**When** llega su respuesta de botón con `payload="habeas_si"`
**Then**
- `registrar_consentimiento(telefono, True)`
- Se responde un mensaje breve de agradecimiento/continuación
- El siguiente mensaje del usuario ya pasa al flujo normal (`generar_respuesta`)

## AC-2: Contacto ya consintió no vuelve a ver el gate

**Given** un contacto con `consentimiento=True`
**When** llega cualquier mensaje entrante
**Then**
- No se muestra el gate; va directo al flujo normal

## AC-3: Aceptación por texto libre equivalente (edge)

**Given** un contacto en estado de gate que responde "sí acepto" como texto (no botón)
**When** llega ese mensaje
**Then**
- Se interpreta como aceptación, se registra consentimiento y continúa
  (tolerancia a clientes que no usan el botón)

## Dependencias

- HU-040, HU-036, HU-039.

## Notas de Implementación

- Rama `payload == "habeas_si"` en el gate de `recibir_webhook`.
- Para AC-3, detección simple de afirmación explícita; ante duda, reofrecer el gate (no asumir).
