# HU-042: Rechazar (No) despide y no atiende

## Descripción

Cuando el usuario toca "No", se registra el rechazo, el bot envía un mensaje de despedida explicando
que sin autorización no puede continuar, cierra la conversación y no procesa más mensajes hasta que
el usuario decida aceptar.

## AC-1: Rechazo despide y cierra

**Given** un contacto con `consentimiento` NULL que recibió el gate
**When** llega su respuesta de botón con `payload="habeas_no"`
**Then**
- `registrar_consentimiento(telefono, False)`
- Se envía mensaje de despedida (no puede atender sin autorización)
- `cerrar_conversacion(telefono, motivo="usuario")`
- **No** se invoca el LLM

## AC-2: Mensajes posteriores tras rechazo reofrecen el gate

**Given** un contacto con `consentimiento=False`
**When** envía un mensaje nuevo más tarde
**Then**
- Se reofrece el gate de consentimiento (puede cambiar de opinión), no se atiende con el LLM

## AC-3: Rechazo por texto libre equivalente (edge)

**Given** un contacto en estado de gate que responde "no, no acepto" como texto
**When** llega ese mensaje
**Then**
- Se interpreta como rechazo, se registra y se despide

## Dependencias

- HU-040, HU-036, HU-034 (cierre), HU-039.

## Notas de Implementación

- Rama `payload == "habeas_no"` en el gate de `recibir_webhook`.
- Mensaje de despedida como constante o parámetro `texto_habeas_rechazo`.
