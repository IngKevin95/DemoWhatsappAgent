# HU-012: Consulta de Licencia (High-Stakes)

## AC-1: Soporte Vigente
**Given** usuario pregunta "¿Tengo soporte?"  
**When** bot consulta Firebird  
**Then** devuelve "Sí, vigente hasta 31/12/2026"

### AC-2: Soporte Vencido
**Given** soporte está expirado  
**When** bot consulta  
**Then** devuelve "Tu soporte venció el 30/6/2024. ¿Quieres renovar?"

### AC-3: Sin Soporte
**Given** usuario no tiene licencia  
**When** bot consulta  
**Then** devuelve "No tengo registro de soporte. ¿Quieres contratar?"

### AC-4: Error de Conexión a Firebird
**Given** Firebird no responde (timeout o conexión rechazada)  
**When** bot intenta consultar  
**Then** devuelve "No puedo verificar tu soporte ahora. Intenta en 2 minutos" + persiste intento en log para reintento automático (EP-002)

## Criterios Técnicos
- Firebird query latencia <100ms
- Graceful degradation si Firebird down (default "sin_soporte", notificar admin)
- Audit logging de quién consultó

## Dependencias
- **EP-001** (tests)
- Firebird datos
