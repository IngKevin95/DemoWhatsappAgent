# HU-005: Detalles de Módulos

## AC-1: Descripción del Módulo
**Given** usuario pregunta "¿Qué incluye Plan Pro?"  
**When** bot consulta base de datos  
**Then** devuelve lista legible de features (ej. "✓ Integración Salesforce, ✓ 24/7 Support, ✗ API ilimitada")

## AC-2: Comparativa Implícita
**Given** usuario pregunta "¿Diferencia entre Plan A y B?"  
**When** LLM procesa  
**Then** devuelve tabla mental clara ("Plan A = $50 sin soporte; Plan B = $100 con soporte")

## AC-3: Módulo No Existe
**Given** usuario pregunta "¿Qué incluye Plan Fantasy?"  
**When** bot consulta y módulo no existe  
**Then** devuelve "No tengo información sobre ese plan. Los planes disponibles son: Pro, Básico, Enterprise"

## AC-4: Descripción Incompleta
**Given** módulo existe pero descripción está vacía en DB  
**When** bot consulta  
**Then** devuelve "Aún no tenemos detalles de ese plan. ¿Hay algo específico que necesites?"

## Criterios Técnicos
- Descripción en base de datos (editable vía NocoDB)
- Formatting legible (bullets, emojis ok)

## Dependencias
- EP-001 (tests básicos)
