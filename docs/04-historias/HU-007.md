# HU-007: Comparativa de Módulos

## AC-1: Solicitud de Comparativa
**Given** usuario pregunta "¿Diferencia entre X e Y?"  
**When** LLM procesa  
**Then** devuelve tabla o punto-a-punto (precio, features, soporte, etc.)

## AC-2: Recomendación Implícita (con Regla Clara)
**Given** usuario pregunta "¿Cuál es mejor para mi caso? Necesito Salesforce + 24/7"  
**When** LLM procesa  
**Then** devuelve "Plan Pro tiene ambas features → recomendado. Plan Básico solo tiene Salesforce."  
<!-- Regla: --> Recomienda el plan con mayor cantidad de features solicitadas por el usuario

## AC-3: Módulos No Comparables
**Given** usuario pregunta "¿Diferencia entre Plan Pro y Cliente Externo?"  
**When** uno de los módulos no existe en DB  
**Then** devuelve "No conozco ese módulo. ¿Quisiste comparar Pro con Básico o Enterprise?"

## AC-4: Ambigüedad Comparativa
**Given** usuario pregunta "¿Cuál me recomiendas?" sin aclarar necesidades  
**When** LLM no puede inferir criterio de recomendación  
**Then** pide contexto: "Para recomendarte, ¿qué feature es prioritario: precio bajo, soporte 24/7, o integraciones?"

## Criterios Técnicos
- Información de módulos en base de datos
- LLM sintetiza comparativa natural

## Dependencias
- EP-001
- Todos los módulos tienen descripción
