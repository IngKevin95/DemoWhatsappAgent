# HU-004: Consulta de Precio

## AC-1: Precio Existente
**Given** usuario pregunta "¿Cuánto cuesta módulo Pro?"  
**When** bot consulta base de datos  
**Then** devuelve precio con moneda (ej. "$50/mes" o "USD 500")

## AC-2: Módulo No Existe
**Given** usuario pregunta "¿Precio de módulo XYZ?"  
**When** módulo no existe en BD  
**Then** bot dice "No tengo información de ese módulo"

## AC-3: Promoción Activa
**Given** hay promoción en ese módulo  
**When** bot consulta  
**Then** menciona el descuento ("Normalmente $100, ahora $80")

## AC-4: Error de Conexión a base de datos
**Given** BD base de datos no responde  
**When** bot intenta consultar precio  
**Then** devuelve "No puedo obtener precios en este momento. Por favor, contacta a comercial." (EP-002 retry)

## Criterios Técnicos
- Query base de datos latencia <100ms
- Precio cached (invalidate si cambia en NocoDB)
- No exponemos ID de BD en respuesta
