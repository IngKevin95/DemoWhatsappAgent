# HU-039: Parsear la respuesta de botón interactivo

## Descripción

`parsear_webhook` hoy solo procesa mensajes `type == "text"` y descarta el resto. Extender para
reconocer respuestas de botón interactivo (`type == "interactive"`, `interactive.button_reply`) y
exponer el id del botón elegido.

## AC-1: Parseo de respuesta de botón

**Given** un payload de webhook con un mensaje `type="interactive"` cuyo `button_reply.id="habeas_si"`
**When** se llama `parsear_webhook(payload)`
**Then**
- Devuelve un `MensajeEntrante` con `tipo="boton"`, `payload="habeas_si"`, `telefono` correcto y
  `texto` = título del botón

## AC-2: Mensaje de texto sigue funcionando

**Given** un payload con un mensaje `type="text"`
**When** se parsea
**Then**
- Devuelve `MensajeEntrante` con `tipo="text"` y `texto` = cuerpo (comportamiento actual intacto)

## AC-3: Tipo no soportado (edge)

**Given** un payload con un mensaje de tipo no manejado (p.ej. `image`)
**When** se parsea
**Then**
- Devuelve `None` (se ignora, como hoy)

## Dependencias

- Se consume en EP-008 (gate de consentimiento).

## Notas de Implementación

- `MensajeEntrante` (base.py) gana `tipo: str = "text"` y `payload: Optional[str] = None`.
- En `meta.py::parsear_webhook`, ramificar por `msg.get("type")`: `text` → actual;
  `interactive` → `msg["interactive"]["button_reply"]` (id/title).
