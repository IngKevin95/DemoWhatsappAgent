# HU-047: Cierre por inactividad con 2 preguntas

## Descripción

Extiende HU-025 (archivada). Hoy `_revisar_inactividad` hace 1 check-in y luego cierra. El negocio
pide 2 preguntas ("¿algo más?") antes de cerrar: si el usuario no responde tras dos check-ins
consecutivos, se cierra con `motivo_cierre="inactividad"`.

## AC-1: Primer check-in por inactividad

**Given** una conversación abierta cuyo último mensaje es del usuario y supera el umbral de inactividad
**When** corre la revisión de inactividad
**Then**
- Se envía `MENSAJE_CHECKIN_1` ("¿algo más en lo que te ayude?")

## AC-2: Segundo check-in si sigue en silencio

**Given** una conversación cuyo último mensaje es `MENSAJE_CHECKIN_1` y supera el umbral
**When** corre la revisión
**Then**
- Se envía `MENSAJE_CHECKIN_2` (frase distinta, sin sonar repetitivo)

## AC-3: Cierre tras el segundo silencio

**Given** una conversación cuyo último mensaje es `MENSAJE_CHECKIN_2` y supera el umbral
**When** corre la revisión
**Then**
- Se envía `MENSAJE_CIERRE`, `cerrar_conversacion(telefono, motivo="inactividad")` y se limpia historial

## AC-4: El usuario responde entre check-ins (edge)

**Given** una conversación en estado de check-in
**When** el usuario responde antes del umbral del siguiente paso
**Then**
- Se reinicia el ciclo de inactividad (vuelve a atención normal); no se cierra

## Dependencias

- HU-034 (cierre de conversación). Extiende HU-025.

## Notas de Implementación

- `_revisar_inactividad` en `agent/main.py`: máquina de estados por contenido del último mensaje
  (patrón actual), ahora con dos check-ins antes del cierre.
- Constantes `MENSAJE_CHECKIN_1` y `MENSAJE_CHECKIN_2` (renombrar el actual `MENSAJE_CHECKIN`).
