# HU-011a: Agendar Cita (High-Stakes)

## AC-1: Agendar Exitoso
**Given** usuario dice "Quiero demo el martes a las 3pm"  
**When** bot invoca `agendar_cita()`  
**Then**
- Evento se crea en Google Calendar (con enlace a Meet)
- Usuario recibe "Evento creado: Demo el 15/7 15:00 en Google Meet"
- (Notificaciones a Soporte/Comercial van en HU-011b)

## AC-2: Sin Disponibilidad
**Given** usuario pide slot ocupado  
**When** bot consulta Google Calendar  
**Then** devuelve 3 slots alternativos disponibles

## AC-3: Confirmación Explícita
**Given** antes de agendar  
**When** bot confirma "¿Confirmas demo el 15/7 15:00 en Google Meet?"  
**Then** usuario debe decir "Sí" explícitamente; solo después se crea evento

## AC-4: Fallo de Google Calendar
**Given** Google Calendar API no disponible  
**When** bot intenta agendar  
**Then** devuelve "No pude agendar. Intenta de nuevo en 2 minutos" (EP-002 retry)

## Criterios Técnicos
- Google Calendar API funciona
- Email delivery confiable
- No agendar sin confirmación explícita
- Audit logging completo

## Dependencias
- **EP-001** (tests integración)
- **EP-003** (audit logging)
- Google Calendar OAuth
