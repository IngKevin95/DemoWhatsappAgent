# HU-014: Estado Detallado de Licencia

## AC-1: Estado Completo
**Given** usuario pregunta "¿Cuándo vence mi soporte?"  
**When** bot consulta Firebird  
**Then** devuelve fecha exacta + módulos incluidos + límites de uso (si aplica)

## AC-2: Sin Soporte Activo
**Given** usuario no tiene licencia vigente en DB  
**When** bot consulta  
**Then** devuelve "No tenemos licencia activa para ti. ¿Te interesa contratar?"

## AC-3: Error de Conexión a Firebird
**Given** Firebird no responde  
**When** bot intenta consultar  
**Then** devuelve "No puedo verificar tu licencia ahora. Intenta en 2 minutos." (EP-002 retry)

## AC-4: Teléfono No Registrado
**Given** usuario no existe en DB Firebird (teléfono no reconocido)  
**When** bot consulta  
**Then** devuelve "No encuentro tu registro. ¿Es tu primer contacto con nosotros?"

## Dependencias
- **EP-001**
- Firebird
