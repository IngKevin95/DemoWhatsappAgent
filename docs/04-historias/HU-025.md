# HU-025: Inactividad Detector

## AC-1: Check-in Automático
**Given** usuario no responde >5 minutos  
**When** background task corre (cada 60s)  
**Then** bot envía "¿Hay algo más que pueda ayudarte?"

## AC-2: Auto-cierre
**Given** usuario no responde >10 minutos  
**When** background task corre  
**Then** bot cierra conversación ("Quedamos en contacto") + archiva historial

## AC-3: Fallo al Archivar
**Given** background task intenta archivar conversación  
**When** falla la escritura en BD (BD caída, timeout)  
**Then** reintenta hasta 3 veces + loguea error sin perder estado de conversación

## AC-4: Respuesta en el Límite
**Given** usuario responde exactamente en el segundo 9:59 (antes del cierre a 10min)  
**When** background task evalúa el timeout  
**Then** NO cierra la conversación (evento de respuesta cancela timer)

## Criterios Técnicos
- Background task cada 60s es imperativo (no más laxo)
- Timers reset en cada mensaje del usuario
- Archivado es soft-delete (no elimina datos, marca como archived_at)
