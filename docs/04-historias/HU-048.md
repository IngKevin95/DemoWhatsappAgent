# HU-048: Enviar catálogos y ofertas usando WhatsApp Carousel Templates

## Épica
epica: EP-011

## Descripción
Como cliente B2B
Quiero poder recibir un catálogo visual de ofertas y productos
Para poder revisar las opciones de manera interactiva sin salir de WhatsApp

## Criterios de Aceptación

### Escenario 1: El usuario consulta las ofertas y se le envía un carrusel
- **Given** que el usuario tiene una conversación activa
- **When** el usuario solicita ver las ofertas activas
- **Then** el sistema detecta la intención y responde usando una plantilla (template) de tipo carrusel
- **And** el carrusel muestra las opciones obtenidas desde la base de datos (Postgres).
