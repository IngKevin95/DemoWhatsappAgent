# HU-003: Disponibilidad 24/7

## Descripción

El bot responde siempre, sin horario. No es "disponible 9am-5pm", es siempre.

## AC-1: Disponibilidad en Horario Off

**Given** usuario envía mensaje a las 22:00 (fuera de horario comercial)  
**When** webhook recibe mensaje  
**Then**
- Bot responde normalmente (no dice "estamos cerrados")
- Respuesta idéntica a si fuera 10am

## AC-2: Sin Degradación de Velocidad

**Given** usuario consulta a cualquier hora  
**When** bot procesa  
**Then**
- Latencia <30s (consistente, sin importar hora)
- Sin "esperar que abra atención" fallacies

## AC-3: Fines de Semana

**Given** usuario consulta sábado/domingo  
**When** webhook recibe  
**Then**
- Misma respuesta que día laboral

## AC-4: Fallo de Infraestructura

**Given** Google Calendar, Postgres, Firebird están caídos  
**When** usuario envía mensaje  
**Then** bot responde "Tengo limitaciones temporales, pero sigo aquí. ¿Cómo puedo ayudarte?" (fallback visible)

## Criterios Técnicos

- **Deploy:** Servicio debe estar en producción 24/7 (EP-005 responsibility)
- **SLA:** Uptime 99% (monitoreado)
- **Fallback:** Si servicios externos fallan (Google, EspoCRM), devuelve respuesta útil, no error

## Tareas

- [ ] Verificar que inactividad checker corre 24/7 (no solo horario comercial)
- [ ] Monitoreo: alertas si bot cae

## Dependencias

- **EP-005:** Production deployment (Docker, monitoring, SLA)
- **EP-002:** Error handling (fallbacks si servicios fallan)

## Anotaciones

Esto es un diferenciador vs. atención humana. "Llamá entre 9-17" no compite.
