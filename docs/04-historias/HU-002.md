# HU-002: Reconocimiento de Intención

## Descripción

Usuario no debe navegar menús. Puede escribir lo que necesita en lenguaje natural ("Quiero saber el precio del plan Pro" o "¿Tengo soporte vigente?") y el bot entiende qué tool invocar.

## AC-1: Consulta de Precio (con mock)

**Given** usuario escribe "¿Cuánto cuesta el módulo X?"  
**When** Gemini procesa el mensaje con function-calling y bot tiene `consultar_precio_modulo()` registrada (real o mock)  
**Then**
- Bot identifica intención = "precio"
- Invoca la tool (mock devuelve $9999 para cualquier módulo en test)
- Devuelve "El módulo X cuesta $9999" (mock) o precio real cuando HU-004 está implementada

**Nota:** AC usa mock en tests; cuando HU-004 se implementa, el mock se reemplaza por la tool real sin cambiar este AC.

## AC-2: Consulta de Disponibilidad

**Given** usuario escribe "¿Hay horarios libres el martes a las 3pm?"  
**When** Gemini procesa  
**Then**
- Bot identifica intención = "disponibilidad"
- Invoca `consultar_disponibilidad_agenda(fecha, hora)` (mock o real)
- Devuelve "Sí, ese horario está disponible" o "No hay"

## AC-3: Consulta de Licencia (con mock)

**Given** usuario escribe "¿Mi soporte está vigente?"  
**When** Gemini procesa y bot tiene `consultar_licencia()` registrada (real o mock)  
**Then**
- Bot identifica intención = "consulta_licencia"
- Invoca la tool (mock devuelve "con_soporte" para cualquier teléfono en test)
- Devuelve "Tienes soporte vigente" (mock) o estado real cuando HU-012 está implementada

**Nota:** AC usa mock en tests; cuando HU-012 se implementa, el mock se reemplaza por la tool real sin cambiar este AC.

## AC-4: Intent Ambiguo

**Given** usuario escribe algo vago ("Tengo una pregunta")  
**When** Gemini no identifica intent claro  
**Then**
- Bot pide aclaración educadamente ("¿Sobre qué? Puedo ayudarte con...")
- No asume, no crea tool que no existe

## Criterios Técnicos

- **Wrapping de telefono:** Tool nunca recibe telefono de LLM, es implícito (anti-hallucination)
- **Tool routing:** Gemini elige tool automáticamente (function-calling)
- **Fallback:** Si tool no existe, Gemini devuelve "No puedo ayudarte con eso"
