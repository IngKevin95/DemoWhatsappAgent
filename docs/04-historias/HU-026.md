# HU-026: Dockerization

## Descripción

Empaquetar la aplicación en Docker para deployment reproducible en staging/production. Incluye Dockerfile multi-stage (build + runtime) y docker-compose para ambiente local productivo.

## AC-1: Dockerfile Multi-Stage Build

**Given** Repositorio tiene source code Python + requirements.txt  
**When** ejecuto `docker build -t demobot:latest .`  
**Then**
- Build stage: instala dependencies, copia código, runs tests (CI gate)
- Runtime stage: imagen minimal (Alpine o Debian slim), solo runtime necesario
- Final image size: <500MB (para cloud efficiency)
- Image includes: Python 3.11+, dependencies from requirements.txt, app code, health check

## AC-2: Docker Compose Productivo

**Given** Dev quiere levantar ambiente similar a production local  
**When** ejecuto `docker-compose -f docker-compose.prod.yml up`  
**Then**
- Services: bot app (Gunicorn), base de datos, optional Redis
- Network: services se comunican via service names (no localhost)
- Volumes: persistent data (base de datos data, logs)
- Health checks: cada servicio tiene `healthcheck`
- Startup order: espera base de datos ready antes de iniciar bot

## AC-3: .dockerignore Configured

**Given** Build Docker image  
**When** COPY . /app ejecuta  
**Then**
- Excludes: .git, __pycache__, .env (credentials), tests/  (opcional), .coverage
- Image size reduced

## AC-4: Environment Variables in Dockerfile

**Given** Container se levanta en production  
**When** app inicia  
**Then**
- Reads from .env file (mounted as volume) o ENV vars del runtime
- No secrets hardcoded en Dockerfile
- Example: `ENV POSTGRES_DB=demobot` (no hardcodea password)

## Dependencias

- Ninguna. Independiente.

## Notas de Implementación

- Dockerfile en raíz del repo
- Multi-stage: `FROM python:3.11 as builder` → `FROM python:3.11-slim as runtime`
- docker-compose.prod.yml en raíz
- Test: `docker build -t test . && docker run test pytest` (CI gate)
- Verify: `docker images` shows demobot:<sha> with reasonable size
