# HU-049: Enviar y recibir archivos adjuntos (PDFs de cotizaciones)

## Épica
epica: EP-011

## Descripción
Como cliente B2B
Quiero poder recibir y descargar cotizaciones o documentos en formato PDF directamente en WhatsApp
Para no tener que revisar mi correo electrónico

## Criterios de Aceptación

### Escenario 1: El bot envía una cotización en PDF
- **Given** que el usuario solicita una cotización del producto
- **When** el bot procesa la solicitud exitosamente
- **Then** el bot envía un mensaje con un documento PDF adjunto
- **And** el PDF contiene los detalles de la cotización generados.

### Escenario 2: El bot recibe un comprobante en PDF o Imagen
- **Given** que el usuario necesita enviar un comprobante
- **When** el usuario adjunta un PDF o imagen
- **Then** el bot descarga el archivo desde los servidores de Meta
- **And** el bot notifica que el documento fue recibido y lo procesa.
