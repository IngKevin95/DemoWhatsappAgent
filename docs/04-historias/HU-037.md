# HU-037: Conversación ligada a su radicado

## Descripción

Añadir `radicado_id` (FK→radicados, nullable) a `Conversación` para cumplir la cadena de dominio
`Radicado → Conversación → Mensaje`. El enlace se setea cuando la conversación deriva en un radicado
(clasificación/escalamiento, EP-009); mientras tanto queda NULL.

## AC-1: Conversación nueva sin radicado

**Given** una conversación recién abierta
**When** se consulta
**Then**
- `radicado_id` es NULL (aún no hay caso/radicado asociado)

## AC-2: Ligar conversación a radicado

**Given** una conversación abierta y un radicado existente (id conocido)
**When** se llama `ligar_radicado(conversacion_id, radicado_id)`
**Then**
- `conversaciones.radicado_id` queda seteado a ese radicado

## AC-3: Radicado inexistente (edge)

**Given** una conversación abierta
**When** se intenta ligar a un `radicado_id` que no existe
**Then**
- Se rechaza (integridad referencial / validación), la conversación no cambia

## Dependencias

- HU-034 (Conversación). Consumida por EP-009 (radicado por conversación).

## Notas de Implementación

- `Conversacion.radicado_id = Column(Integer, ForeignKey("radicados.id"), nullable=True)`.
- Helper `ligar_radicado(conversacion_id, radicado_id)` en `agent/memory.py`.
- El seteo real ocurre en EP-009; aquí solo se provee el campo + helper.
