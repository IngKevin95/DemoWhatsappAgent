# HU-006: Promociones

## AC-1: Listar Ofertas
**Given** usuario pregunta "¿Hay promociones?"  
**When** bot consulta tabla Oferta  
**Then** devuelve lista de descuentos vigentes con fecha de vencimiento

## AC-2: Promoción Expirada
**Given** promoción está fuera de rango de fechas  
**When** bot consulta  
**Then** no la muestra (o dice "Esa promoción venció")

## AC-3: Sin Promociones Activas
**Given** tabla Oferta no tiene registros vigentes  
**When** bot consulta  
**Then** devuelve "No hay promociones activas en este momento. Revisa nuestros planes regulares."

## AC-4: Error de Conexión
**Given** Postgres no responde  
**When** bot intenta consultar Oferta  
**Then** devuelve "Intenta de nuevo en 2 minutos" (EP-002 retry) sin revelar error interno

## Criterios Técnicos
- Consulta Oferta table con date range check
- Latencia <100ms

## Dependencias
- EP-001
- Postgres data
