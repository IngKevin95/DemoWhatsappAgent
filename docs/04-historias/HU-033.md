# HU-033: Secrets Scrubbing en Logs

## Descripción

Garantizar que tokens de API, credenciales de base de datos, y otras secrets NUNCA aparezcan en logs, ni siquiera en exception logs. Scrubbing automático de campos sensibles.

## AC-1: DATABASE_URL Never in Logs

**Given** Exception en conexión a base de datos  
**When** exception se loguea  
**Then**
- Log entry registra: exception type, message, traceback
- DATABASE_URL value redactado como: `***REDACTED***`
- Log muestra: `DATABASE_URL: ***REDACTED***` (no el valor real `postgresql://user:pass@host/db`)
- Test: grep en logs por "postgresql://" retorna 0 matches

## AC-2: GOOGLE_* Tokens Never in Logs

**Given** Exception en Google Calendar API call  
**When** exception se loguea en `integrations/google.py`  
**Then**
- Fields redactados: GOOGLE_APPLICATION_CREDENTIALS, GOOGLE_OAUTH_TOKEN, access_token
- Log muestra: `GOOGLE_OAUTH_TOKEN: ***REDACTED***`
- HTTP headers redactados: Authorization header logged as `***REDACTED***`
- Test: grep en logs por "ya29" (Google token prefix) retorna 0 matches

## AC-3: META_API_TOKEN Never in Logs

**Given** Exception en Meta Webhook signature validation  
**When** exception se loguea  
**Then**
- META_API_TOKEN redactado como: `***REDACTED***`
- Log muestra exception con token hidden
- Test: grep en logs por cualquier formato de token Meta retorna 0 matches

## AC-4: CI Gate Blocks Secret Leaks

**Given** PR intenta mergear código con secrets en logs  
**When** CI test `test_secrets_not_in_logs.py` corre  
**Then**
- Test scans todos los logs generados durante test suite
- Test busca patterns: `postgresql://`, `ya29`, `AKIA`, `access_token=`, etc.
- Si encontrados: test FALLA, PR bloqueado
- If test passes: PR puede continuar

## Dependencias

- Requiere actualización de `agent/middleware/logging.py`
- Requiere refactor exception logging en `integrations/google.py`, `integrations/espocrm.py`, `agent/db.py`
- Requiere test: `tests/security/test_secrets_not_in_logs.py`

## Notas de Implementación

- Logging filter class: `SecretsFilter` que intercepta todos los logs
- Pattern list: DATABASE_URL, GOOGLE_*, META_*, access_token, password, api_key, etc.
- Replacement: `***REDACTED***` (or `[REDACTED_<TYPE>]`)
- Exception handler in integrations: catch exceptions, don't log `response.text` completo (log response.status_code only)
- CI gate: run `grep -E 'postgresql://|ya29|AKIA|access_token=' logs/* && exit 1 || exit 0`
