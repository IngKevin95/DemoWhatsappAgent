# HU-051: Adaptador y Webhook para Telegram

## Descripción
**Como** arquitecto de software
**Quiero** un adaptador y endpoint dedicado para Telegram
**Para que** el bot pueda recibir mensajes de Telegram de la misma forma que recibe de Meta, desacoplando el core conversacional del proveedor específico.

## Criterios de Aceptación

### Scenario 1: Recepción de mensaje de texto por Telegram
- **Given** que el bot tiene configurado el webhook de Telegram activo
- **When** un usuario envía un mensaje de texto por Telegram
- **Then** el webhook de Telegram lo recibe
- **And** el adaptador parsea el mensaje a la estructura estándar `MensajeEntrante`
- **And** el flujo pasa al `generar_respuesta()` del brain de la misma manera que en Meta.

### Scenario 2: Envío de mensaje de texto a Telegram
- **Given** que el `brain` ha generado una respuesta para un usuario de Telegram
- **When** se llama al método `enviar_mensaje` del proveedor Telegram
- **Then** se hace una petición HTTP a la API de Telegram Bot con el texto y el `chat_id` correspondiente
- **And** el usuario recibe el mensaje en Telegram.

## Detalles Técnicos
- Requiere crear `agent/providers/telegram.py` implementando la base `ProveedorWhatsApp` (o refactorizar la base a `ProveedorMensajeria`).
- Añadir el endpoint `/webhook/telegram` en `agent/main.py`.
- Integración con la API de Bot de Telegram (`https://api.telegram.org/bot<token>/sendMessage`).
