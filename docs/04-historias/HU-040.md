# HU-040: Saludo + solicitud de consentimiento a contacto nuevo

## Descripción

Al llegar el primer mensaje de un contacto sin consentimiento registrado, el bot responde con saludo
+ el texto de política de tratamiento de datos (habeas data) y botones Sí/No, ANTES de invocar al
LLM. El texto de política es editable vía parámetro.

## AC-1: Contacto nuevo recibe el gate

**Given** un contacto con `consentimiento` NULL (nunca preguntado)
**When** llega su primer mensaje entrante
**Then**
- Se abre conversación (HU-034) y se guarda el mensaje entrante
- Se envían botones `[(habeas_si,"Sí, acepto"),(habeas_no,"No")]` con el texto de `texto_habeas_data`
- **No** se invoca `generar_respuesta` (el LLM no corre)

## AC-2: Texto de política editable

**Given** el parámetro `texto_habeas_data` configurado en la tabla `parametros`
**When** se arma el mensaje de consentimiento
**Then**
- El cuerpo usa ese valor (no texto hardcodeado)

## AC-3: Re-solicitud si sigue pendiente (edge)

**Given** un contacto que ya recibió el gate pero aún no respondió (sigue `consentimiento` NULL) y
envía otro texto libre
**When** llega ese mensaje
**Then**
- Se reofrece el gate una vez más y no se invoca el LLM

## AC-4: Parámetro ausente (error)

**Given** que no existe el parámetro `texto_habeas_data`
**When** se arma el gate
**Then**
- Se usa un texto por defecto seguro y se loguea la ausencia (no se rompe el webhook)

## Dependencias

- HU-034 (Conversación), HU-036 (consentimiento), HU-038/039 (botones).

## Notas de Implementación

- Gate al inicio de `recibir_webhook`, antes del bloque `generar_respuesta`.
- Parámetro `texto_habeas_data` leído con `consultar_parametro` (patrón existente en `tools.py`).
