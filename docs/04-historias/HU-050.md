# HU-050: Transcribir notas de voz del usuario a texto (Voice-to-Text)

## Épica
epica: EP-011

## Descripción
Como cliente B2B en movimiento
Quiero poder enviar mis consultas comerciales mediante una nota de voz
Para no tener que escribir mensajes largos cuando estoy ocupado

## Criterios de Aceptación

### Escenario 1: El usuario envía una nota de voz válida
- **Given** que el usuario graba y envía una nota de voz
- **When** el webhook de Meta recibe el mensaje de tipo `audio`
- **Then** el sistema descarga el archivo de audio
- **And** el sistema utiliza un servicio STT (como Google Cloud STT o Whisper) para transcribirlo
- **And** el texto transcrito se inyecta al pipeline del LLM como si hubiese sido un mensaje de texto.
