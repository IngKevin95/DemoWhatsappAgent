## Assumptions & Constraints

1. **Gemini API mocked:** Real API calls tested separately (E2E only, post-deploy)
2. **External services mocked:** Google Calendar, EspoCRM, Firebird via pytest fixtures
3. **Database:** SQLAlchemy test session with rollback (no side effects)
4. **Secrets:** Loaded from `.env.test` (not committed, excluded from coverage)
5. **No production data:** All tests use fixtures + synthetic data
